<table>

- Glassmorphic **code window that types itself** — `krishna.js` with syntax highlighting
- Breathing violet orb + rotating orbit ring + floating glass badges
- GSAP cinematic entrance + **Lenis** buttery smooth scrolling

- 5 interactive cards — **3D tilt, cursor glare, rotating gradient ring borders**

## 🚀 Run it

```bash
# just open index.html — or serve it:
python -m http.server 8740
# → http://localhost:8740
```

## 📁 Structure

```
portfolio/
├── index.html          # the whole site — one page
├── styles.css          # theme variables, animations, layouts
├── script.js           # typing, gallery, form, motion
├── og-image.jpg        # WhatsApp / LinkedIn share preview
├── media/              # screenshots, renders, videos
│   ├── proj-*.jpg      # project card images
│   ├── render-*.jpg    # Blender renders
│   └── *.mp4           # Blender animations
└── client-demo/        # full sample client website
    ├── index.html      # animation portfolio demo
    ├── about.html · projects.html · contact.html
    └── css/ · js/ · assets/
```

## 🛠️ Built with

| Purpose | Tool |
|---|---|
| Structure & styling | HTML5 · CSS3 (custom properties, grid, clamp) |
| Interactions | Vanilla JavaScript |
| Motion | GSAP + ScrollTrigger |
| Smooth scroll | Lenis |
| Contact form | FormSubmit (→ Gmail) |
| Fonts | Space Grotesk · Inter · JetBrains Mono |
